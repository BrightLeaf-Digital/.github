# BrightLeaf Digital

BrightLeaf Digital is the engineering arm of the BrightLeaf family of companies — including BrightLeaf Giving, Expat and more. We build the WordPress plugins, PHP libraries, and internal tooling that power our platforms.

All software we distribute publicly started as something we built and use ourselves. We open-source tools when we think others might find them useful, and we try to be good citizens of the ecosystems we depend on.

## What we build

- **PHP API clients** — including an actively maintained [Asana API client](https://github.com/BrightLeaf-Digital/asana-client) that replaces the deprecated official library
- **WordPress plugins** — Gravity Forms extensions, workflow automation, payment integrations, and more
- **Internal tooling** — CI/CD pipelines, deployment automation, and shared libraries across our plugin suite
